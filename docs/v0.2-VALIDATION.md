# v0.2 开发与验收记录

状态：开发分支实现中，**尚未通过全部发布门槛**。版本仍为 0.1.0，没有提交 Git，没有替换原有服务。验证日期：2026-10-16 至 2026-10-17（Asia/Shanghai）。

## 已验证范围

- 管理会话保护业务 API、更新流、当前内容及缩略图；HttpOnly / SameSite / HTTPS Secure、CSRF、退出和重启失效。编码路径也必须受保护；新增 `/%61pi/monitors` 回归，防止 Fastify 解码路由绕过原始 URL 前缀判断。
- AES-256-GCM 随机 nonce、身份及 revision AAD、错钥与篡改拒绝。启用过身份保护后，即使身份已删除或部署密钥缺失，也不会重新开放私人历史。
- 真实 Chromium 恢复 HttpOnly Cookie、Cookie 请求头、localStorage、IndexedDB；输入越界、公共与私有后缀、格式错误和 200 登录页不替换旧状态。新增 `tldts@7.4.18` 已精确锁定并加入 Docker 运行依赖。
- 同身份先排队再占全局槽；账号隔离、轮换 Cookie、提取失败时保存有效会话、采集中撤销后的旧结果丢弃，以及 TEXT / LIST 基线重建均有回归。独立审查发现的排队验证旧状态、规则修改后状态回写、旧身份失败误阻塞新绑定和异步跳转登录视图四项问题，均补上修复前失败的回归后修正。
- 200 登录页、登录跳转、401、单页面 403 和成功标记失配分别处理。阻塞不改用户开关，不推进基线；同账号恢复保留基线，换账号重建。提醒持久化、去重和重试；默认通知摘要。事件持久化隐私标记，解绑后旧待发事件仍不会泄漏正文。
- 配对码一次性且限身份；显式保存、部署端验证、提交重放、TTL、心跳失联、取消、授权修订与服务重启均有受控回归。助手退出关闭独立浏览器，不写明文状态文件。保存提交成功后立即向助手确认，后续逐任务恢复不会拖延上传响应，该问题也经过修复前失败的回归验证。真实 Chromium 覆盖批准 / 未批准的 SSO 弹窗；服务真实断网后约 30.2 秒关闭助手浏览器。受控 SSO 通过测试专用 HTTP 代理解析主机，生产公共地址限制没有放宽。
- 从 Git HEAD 的实际 v0.1 数据库代码创建旧库副本，保留任务、快照、已见 Key、执行记录和待发通知；物理备份、升级、完整性检查与恢复后逐行核对通过。
- 最终 `npm test` 54/54 全部通过（约 100 秒，含真实断网 30 秒等待）；`npm run build`、助手独立 TypeScript 检查和 `git diff --check` 通过。

现有 `127.0.0.1:3000` 服务未被操作。补充使用一次性 Docker CLI 运行容器执行与仓库 **逐字节一致** 的 `deploy.sh`：完整构建、容器替换和健康检查通过。被测 Compose 服务仅映射宿主 `4183`，数据和密钥均独立；脚本固定的 `127.0.0.1:3000` 健康检查位于运行容器的独立网络命名空间，经 TCP 转发连接被测服务，没有连接宿主现有服务。

再次执行同一脚本后，身份元数据保留、旧管理 Cookie 失效、重新解锁成功，部署锁已释放。最初的复测探针遇到容器重建关闭旧 keep-alive 连接；改用新连接后验证通过，无产品代码变更。
