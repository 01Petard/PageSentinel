# PageSentinel 项目规划

版本：v0.1  
整理日期：2026-10-16  
状态：v0.1 已实现，受控回归与单容器验证已通过；见 [实施与验收记录](../开发进度.md)

**PageSentinel（页面哨兵）是一个本地优先、可自部署的网页变化监控工具。** 用户配置网址和提取规则，服务端持续检查公开网页，识别区域文本变化或列表新增条目，保存变化证据并发送通知。

核心目标：说清楚哪里变了、具体变了什么，以及这次变化是否值得通知。

## 首版范围

- 两种模式：TEXT 区域文本变化、LIST 列表新增。
- 两个主页面：监控任务列表、监控详情。
- 一个通知渠道：ntfy。
- 一套部署：Vue + Fastify + Playwright + SQLite，单实例、单容器。
- 目标规模：个人使用，约 5—20 个任务。

首版完成标准：创建规则 → 测试提取 → 建立基线 → 自动检查 → 记录有效变化 → 通知 → 查看证据。先让这条流程可靠运行，再增加能力。

本目录保留 v0.1 原始规划。应用源码与启动说明位于项目根目录，实现与验证结果见 [实施与验收记录](../开发进度.md)。一个月持续试运行尚待实际部署后观察。
