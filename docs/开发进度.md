实现约定：浏览器和通知 IO 均在数据库事务外；规则修改使用版本号隔离；列表历史不随成功采集清空；删除级联清理。仅测试工厂显式注入本机地址白名单，生产入口无法通过环境变量关闭公共地址校验。

个人 ntfy 主题未配置；接口、重试与恢复使用本地真实 HTTP 接收端验证，用户主题实际投递需配置后确认。一个月持续试运行尚待部署观察。连续相同采样仍是启发式判断，不能保证所有 SPA 完全加载。容器默认阻断 IPv6 和内网地址，包含内网 ntfy；详见根目录 README。

## 视觉与内容检阅改版

列表、详情与规则抽屉采用紫色、青柠和淡紫底色，补充悬停、状态反馈与减少动态效果适配。“区域文本发生变化”统一改为“区域变化”。新增内容独立展示并可复制；完整对比可切换统一/并排，左右列与保存的前后快照一致，自动轮询不重置选择。手机端左右列同时可见，320px 与 390px 检查无页面横向溢出；仅删除时显示明确提示。新纯逻辑回归覆盖替换、行数不等、纯新增、纯删除、空行与字面 HTML 内容；真实浏览器验证快照重建、切换和新增内容复制。示例任务仅存在于独立验收服务。

## 自定义调度、通知与当前内容

根据后续需求完成：时分自定义间隔（小时 0—24、分钟 0—60，合计至少 1 分钟）；每次下次检查时间随机增加或减少 5—10 秒；扫描精度 1 秒；强制刷新全部包含暂停任务并在完成后重置调度时间。各任务单独控制自动检查，已按最新要求移除全局开关与全局调度限制。启用、关闭操作原子写入执行记录，重复保存同一状态不重复记账，采集结果与变化通知不受影响。

详情首先展示最近成功采集内容与真实 JPEG 页面缩略图，失败保留上次成功内容；规则重建时清除旧内容与缩略图。当前内容桌面等宽两列，两内容框高 420px；手机上下排列，两框高 320px，长内容局部滚动。执行记录增加来源、摘要、秒级时间、错误码和耗时。基线说明移至编辑器与详情。

右上角通知中心读取最近检查结果，页面消息与浏览器通知分别设置，首次读取历史静默，跨标签页按已投递结果 ID 去重。控制操作保留在执行记录中，不作为内容检查结果推送。浏览器通知仅在页面打开期间接收，未实现 Web Push。
